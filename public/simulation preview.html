Download & ProjectIntroduction

Download the full City of Justice project to explore the
JustAcademy, interact with AI-powered avatars, and
use the new OSINT module for training.

This 3D project was developed to provide an immersive experience inside the JustAcademy,
a virtual environment designed for professional training in the judicial sector.
By downloading the project, you will be able to:

  • Explore the City of Justice in 3D
  • Interact with intelligent avatars capable of real-time dialogue
  • Access the OSINT module for investigative simulations
  • Use integrated training materials inside a modern virtual environment

To ensure proper operation of the project, please follow the instructions below carefully.

1. Extract the file

After completing the download, you will
find a ZIP compressed folder.

  • Right-click the file
  • Select “Extract All”
  • Wait for the extraction to complete

2. Launch the project through Unreal Engine

Inside the extracted folder, you will find an
executable file linked to Unreal Engine.
Procedure:
1.Open the extracted folder
2.Locate the project’s .exe file
3.Double-click it to start the application
4.Wait for the engine to load

3. Installation of complementary
programs (IMPORTANT)

On first launch, the system may request
the installation of additional components
required for the project to function (e.g.,
Visual C++ Redistributables, DirectX, or
other dependencies).
